# 📆 EventReminder

C#とWPF(.NET Framework 4.8)で開発された、シンプルで実用的なデスクトップイベントリマインダーツールで、ローカルのJSONストレージをサポートし、ログインもインターネット接続も不要です。

---

## 🧩 プロジェクト概要

このプロジェクトは、MVVMフレームワークを使用しない純粋なWPFアプリケーションで、C#入門レベルのユーザーがイベント保存とウィンドウ・インタラクション処理の基本的な流れを理解するのに適しています。すべてのイベントはJSONファイルとして保存され、読み込まれます。

---

## ✨ 特徴

- ✅ メイン画面には全イベントのリストが表示される（イベント名/時間/ラベル）
- ✅ 詳細（名前、時間、リマインダー、繰り返しルール、説明）を編集するには、イベントをダブルクリックします。
- ✅ アライバルアラート」と「アーリーアラート」機能をサポート。（開発中）
- ✅ イベントは 「毎年繰り返す 」か 「繰り返さない 」かを選択できる（誕生日に適用される）
- ✅ データはローカルのJSONとして保存され、データベースは不要。
- ✅ イベントの追加、変更、削除をサポート
- ✅ JSONアーカイブのパスはリアルタイムで表示されます（デバッグやバックアップが容易です）。

## 🛠 技術細節

- **言語**：C#
- **フレームワーク**：.NET Framework 4.8
- **UI 技術**：WPF（非 MVVM 架構）
- **データ保管**：使用 `Newtonsoft.Json` 套件進行序列化至本地 JSON 檔案
